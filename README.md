# 동화 극장 · Story theatre

https://dmitriiree.github.io/fairytales/

Korean children's plays as interactive cartoon players: voices, subtitles (KO / RU / EN) and a rehearsal mode — pick a role, hear the model line, say it yourself, press Space.

- 브레멘 음악대 · The Bremen Town Musicians — https://dmitriiree.github.io/fairytales/bremen/
- 백설 공주 · Snow White — https://dmitriiree.github.io/fairytales/snow-white/

Voices: ElevenLabs (eleven_v4). Korean scripts are school play adaptations of the Brothers Grimm tales.
